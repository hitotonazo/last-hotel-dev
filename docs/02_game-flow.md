# 3. PHASE0

## 表示

-   `index.html`：完全な通常ホテル
-   `facilities.html`：`floor-map-normal.webp`
-   `gallery.html`：通常ギャラリー

Gallery写真の031は最初から写っていてよい。これは「最初の異常」であり、別のシステム異常を先に出さない。

## 最初の異常の成立条件

031は初見でも意図的な異常だと判断できる強さにする。

-   周囲と明確に違う真っ赤な服
-   同じ人物が複数年代に存在
-   同じ顔・髪型・体型
-   刺青
-   大型リストバンド
-   031だけ視線を引く明度

単に「少し怪しい男性」程度に弱めない。

# 4. PHASE1｜031

## 発生場所

`gallery.html`

## 操作

031本人をクリック。

画像全体を雑にクリック対象にせず、人物付近に十分なhit
areaを設定してよい。 SPでも44px以上の操作領域を確保。

## 初回クリック処理

1.  二重操作防止
2.  `modules` のサイト改変演出を実行
3.  `discovered031 = true`
4.  `phase = phase1` 相当へ更新
5.  演出完了後、内部管理情報を表示
6.  state保存

## 表示情報

``` text
管理番号：031
入館：2014年8月17日
滞在期間：4,382日
状態：滞在中
外出記録：0
入館理由：事件関与
滞在区画：10階
```

## プレイヤーが理解すべきこと

-   この人物は単なるイベント参加者ではない
-   2014年から異常な長期滞在をしている
-   外出記録がない
-   ホテル内部で管理番号を与えられている
-   「10階」という未知の区画がある

## 次へ進む理由

**「ホテルに10階があっただろうか？」→ facilitiesの館内図を確認する。**

ページ側から「次は館内図を見てください」と直接指示しない。

## 再訪

`discovered031 = true` の場合：

-   同じ改変演出を再生しない
-   内部管理情報は発見済み状態として確認可能
-   PHASE3でgalleryへ戻っても031発見状態を維持

# 5. PHASE2｜隠された10F

## 発生場所

`facilities.html`

## 前提

`discovered031 = true`

## 初期表示

`floor-map-normal.webp`

B1〜9Fのみ。

## 唯一の主要異常

館内図の9F上部／階数表示付近に、クリック可能な不自然な欠け・表示ノイズを1箇所だけ出す。

条件：

-   「10Fはこちら」等の説明文を出さない
-   小さすぎて見つからない異常にしない
-   他に同格の異常を出さない

## 初回クリック処理

1.  操作ロック
2.  modules改変演出
3.  `discovered10F = true`
4.  `phase = phase2`
5.  `floor-map-normal.webp` → `floor-map-hidden.webp`
6.  10F宿泊者管理情報を展開
7.  state保存

## 改変後館内図

`floor-map-hidden.webp`

必須：

-   通常版と基本デザイン/配置は同じ
-   10Fだけ赤く明確に追加
-   「特別宿泊フロア」
-   「業務用エレベーター」
-   「2021年増設」

禁止：

-   B2表示
-   地下実験施設表示
-   人体実験の示唆を図面上で断定

## 10F管理対象

実画像：031 / 017 / 062。

全体8名程度に見せる。

共通傾向：

-   犯罪事件への関与
-   組織からの逃亡
-   身元を捨てたい
-   外部追跡を避けたい
-   外出記録0が多い

この時点での**第一の真相**：

**HOTEL NESTRAは、社会から姿を消したい人間を秘密裏に匿っている。**

ここではまだ「実験対象」と断定しない。

## 次へ進む手がかり

``` text
業務用エレベーター
2021年増設
ホテル改装工事に伴い新設
```

「ホテル改装工事」を含め、2021年の過去記録を調べる理由を強くする。

## 次へ進む理由

**「2021年に何の工事をしたのか？」→ galleryの2021年改装記録を確認。**

# 6. PHASE3｜2021年改装記録

## 発生場所

`gallery.html`

## 前提

`discovered10F = true`

## 2021年記録

`gallery-renovation.webp`

-   031なし

-   背景に業務用EV入口

PHASE2前は普通の改装記録。
PHASE2後は「2021年増設」と結びついて調査対象になる。

## 初回クリック処理

1.  操作ロック
2.  modules改変演出
3.  `discoveredRenovation = true`
4.  `phase = phase3`
5.  `facility-extension-plan.webp` を展開/差し替え

## 工事図

プレイヤーに理解させること：

-   2021年の工事で業務用EVが地下へ延伸
-   B1より下にB2が存在
-   B2はホテル本体の既存部分ではなく後付けの「地下増設区画」
-   B2には管理区画、観察室、処置室、機械室等がある

禁止：

-   「人体実験施設」と図面上で明記
-   ここで研究の全貌を説明

## 次の唯一の異常

`facility-extension-plan.webp` 内の赤いB2「地下増設区画」。

B2をクリック可能にする。

## B2初回クリック

1.  modules改変演出
2.  `discoveredB2 = true`
3.  `phase = phase4`
4.  `underground.html` へ遷移

同一クリックで複数回遷移しない。

# 8. TRUTH

詳細は `03_truth-ending-images.md`。

真相はプレイヤー向け解説ではなく内部資料の照合。

ここで最終的に理解できる構造：

``` text
当初：身元を消したい人間を高額で匿う
↓
ホテル側が「追跡されにくい人間」に着目
↓
B2研究区画と業務用EVを増設
↓
特別宿泊者を長期研究対象へ転用
↓
制度の目的が反転
↓
実験対象を確保するため、人間を社会から消す
```

最後の一文をナレーションとしてそのまま大書きする必要はない。資料を読めばこの構造が明確に理解できるようにする。

# 9. ENDING / 締め演出

Ending専用ページを作らない。 `truth.html` 最下部で実行。

順序：

1.  `現在の空室：3室`
2.  数秒待機
3.  `現在の空室：4室`
4.  Gallery内の031を含む写真を別状態へ変更/031が消えた状態を反映
5.  10F内部管理記録から031を消す
6.  何が起きたか説明しない
7.  HOTEL NESTRAのコピー
8.  X共有

重要：**通常TOPへ戻さない。**

`endingTriggered = true`
を保存し、reload後に締め演出を毎回最初から再生しない。

# 14. エラー耐性

-   localStorage利用不可でも通常ページ自体は表示
-   parse失敗時は初期化
-   不正phaseは安全な初期状態
-   連打防止
-   演出中の多重発火防止
-   reload後に状態復元
-   back後に状態復元
-   031発見後のgallery再訪でPHASE1演出を再発させない
-   PHASE3でgalleryへ戻った時に2021記録を調査可能
-   ending後reloadで031が復活しない
