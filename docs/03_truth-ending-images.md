# 2-1. Hero画像4枚の共通ルール

`index.html` Heroは以下4枚を順番に使用する。

``` text
hero-hotel.webp
hero-room.webp
hero-lounge.webp
hero-restaurant.webp
```

4枚は同一ホテルの施設として視覚的な統一感を持たせる。

共通方向：

-   横長Hero用途
-   高級都市型ホテル
-   上品、静か、現代的
-   ブラック、ダークブラウン、深いグリーン、暖色照明を基調
-   写真内に文字、ロゴ、透かしを入れない
-   映画的すぎる照明にしない
-   過度なボケを避ける
-   広告写真のような誇張を避ける
-   人物がいる場合、肌の過剰補正、光沢のあるAI風の顔、全員同じ表情、不自然な手や身体を避ける
-   ARGの異常、031、リストバンド、10F、B2等をHeroへ混入させない

各画像の役割：

-   `hero-hotel.webp`：ホテル全体・外観
-   `hero-room.webp`：滞在体験・客室
-   `hero-lounge.webp`：館内の静けさと高級感
-   `hero-restaurant.webp`：ホテルサービス・夜のレストラン

Hero専用画像と通常セクション用 `hotel-room.webp` / `hotel-lounge.webp` /
`hotel-restaurant.webp`
は用途を分ける。Heroでは横長トリミングとコピーを重ねられる余白を優先する。

# 9. truth.html 基本

## 9-1. 目的

プレイヤーに答えをナレーションで説明するページではない。

**現実に存在しそうな内部文書・研究記録・設備仕様・改訂履歴を上から順に読むことで、プレイヤー自身が全体像を組み立てるページ。**

## 9-2. 1ページ完結

タブ化、複数ページ化、3分割画面化、連続モーダル化をしない。

上から下へスクロールして理解できる構成。

## 9-3. デザイン

-   黒〜濃いチャコール/濃紺
-   通常サイトより明確に不穏
-   企業内部資料・研究報告書の印象
-   1px程度の区切り線
-   セクション番号
-   小さな英字ラベルは補助的に可
-   写真、表、短い段落を組み合わせる
-   全カードを太枠で囲まない
-   可読性最優先

禁止：

-   サイバーSF UI
-   意味不明な英語羅列
-   赤点滅だらけ
-   過度なグリッチ
-   読めない小文字

# 12. truth セクション03｜対象031 経過観察記録

使用：

-   `truth-research-02.webp`
-   Gallery写真の小再掲可

## プレイヤーが理解すべきこと

**031は長期宿泊者ではなく、長期間にわたる研究対象として観察・投与されていた。**

HTML情報例：

``` text
対象番号：031
観察区分：長期
観察開始：XXXX年
投与回数：XX
経過：継続観察
```

数値は骨子と矛盾しない範囲で必要最小限。CodeXが医学的な詳細設定を独自創作しない。

Gallery写真を「観察365日目」「観察1,095日目」等の添付資料として再解釈する場合、日数は実際の年代関係と矛盾しないよう確認する。

重要：Galleryのイベント写真が、実は長期観察用の記録にも使われていたと理解できる構成。

# 14. truth セクション05｜対象者受入基準 改訂履歴

使用：`truth-research-01.webp`

## プレイヤーが理解すべきこと

**制度の目的が「消えたい人を受け入れる」から「研究対象を確保するために人を消す」へ変質した。**

改訂履歴を時系列で見せる。

初期：

``` text
本人申請
外部追跡回避希望
```

中期：

``` text
紹介
仲介
```

後期：

``` text
外部依頼
研究対象適合者
```

本人が「消えたい」と希望していない対象まで含まれることが読み取れるようにする。

ここが真相の目的反転を理解する最重要資料。

# 20. 真相ページ検証

必ず初見視点で確認。

各セクションで1つの理解目標が達成されること：

1.  当初は匿うサービス
2.  研究目的でB2増設
3.  031が被験者
4.  wristbandが監視/制御装置
5.  受入制度の目的が反転
6.  全要素が一つの仕組みとして接続

確認事項：

-   専門知識なしで理解できる
-   重要情報が日本語
-   文章だけになっていない
-   画像だけに依存していない
-   写真/図/表/短文のバランス
-   通常ホテルとのデザイン差がある
-   不穏だが読める
-   031の人物同一性が保たれる
-   2021年増設が回収される
-   wristbandが回収される
-   Gallery写真が回収される
-   Endingで説明しすぎない

------------------------------------------------------------------------

# 21. 最終禁止事項

-   真相を一文だけ表示して終わらせる
-   逆に長大な小説形式にする
-   画像内文字を正式資料として使う
-   真相をタブ化してCodeX独自のシステムUIにする
-   031を別人物画像へ変更
-   031の赤スーツをtruth-research-02へ戻す
-   wristbandを別デザインへ変更
-   B2図面で先に人体実験と明記
-   空室4室の意味を文章で説明
-   031の最終状態を死亡と断定
-   Ending後にTOPへ戻す
-   X共有文を変更
