NESTRAは普通の上質なホテル」だけ**。

以下を示唆しない：10F、031、犯罪者、逃亡者、B2、研究、実験。

## 3-2. 推奨セクション順

1.  Header
2.  Hero
3.  HOTEL NESTRAについて / Concept
4.  Rooms
5.  Restaurant
6.  Lounge / Facilities teaser
7.  Long Stay
8.  Gallery teaser
9.  News / Access
10. Footer

参考サイトのレイアウトをコピーせず、HOTEL NESTRA独自の構成にする。

HOTEL NESTRA

ARGを示すコピーを追加しない。

画像：`hotel-about.jpg`

# 4. facilities.html

## 4-1. ページ目的

通常時は館内施設を紹介するページ。
PHASE1で「滞在区画：10階」を取得したプレイヤーが、ホテルに10Fが存在するか確認する場所。

## 4-2. 通常セクション順

1.  Page Hero / title
2.  館内施設概要
3.  Lounge / Restaurant等の紹介
4.  Floor Guide
5.  Footer

ページを過度に長くしない。

## 4-3. 通常館内図

画像：`floor-map-normal.png`

必須：

-   B1〜9F
-   10Fなし
-   B2なし
-   写真なしの上品でシンプルな館内図
-   ARGノイズなし

通常状態で10F用の不自然な大空白を作らない。

## 4-4. PHASE2時

詳細条件は `02_game-flow.md`。

PHASE1で031の内部情報を取得済みの場合、館内図付近に唯一の主要異常を出す。

クリック後：

`floor-map-normal.png` → `floor-map-hidden.png`

改変版で初めて：

-   10F
-   特別宿泊フロア
-   業務用エレベーター
-   2021年増設

を確認可能にする。

**B2はこの時点で直接表示しない。**

## 4-5. 10F宿泊者表示

10F発見後、同ページ内に特別宿泊者の内部管理情報を表示。

実画像：

-   `guest-031.jpg`
-   `guest-017.jpg`
-   `guest-062.jpg`

全体は8名程度の管理対象が存在するように見せてよいが、追加人物画像は生成・捏造しない。残りは画像なしの管理カード、シルエット、NO
IMAGE等で構成可。

カード情報例：

-   管理番号
-   入館年
-   滞在期間
-   外出記録
-   入館理由の短い分類

全員に同型管理端末を装着している設定。

ここでプレイヤーに理解させること：

**HOTEL
NESTRAは、事件関与者・逃亡者・身元を捨てたい人間などを秘密裏に匿っている。**

ただし、この時点では「人体実験」を明かさない。

# 5. gallery.html

## 5-1. ページ目的

通常時はホテルの過去イベントギャラリー。
同じページを2回、異なる知識で調査させる。

1回目：031を発見する。\
2回目：2021年のEV増設情報を得た後、改装工事記録を調べる。

## 5-2. 通常セクション

1.  Page title
2.  年代別Gallery
3.  2014
4.  2017
5.  2020
6.  2021改装記録
7.  2026
8.  Footer

イベント名・年など通常の短いキャプションを付ける。

## 5-3. 使用画像

-   `gallery-2014.jpg`
-   `gallery-2017.jpg`
-   `gallery-2020.jpg`
-   `gallery-renovation.jpg`
-   `gallery-2026.jpg`

031が写る各年代写真は、**場所・構図・他の客を変える**。
同じ集合写真の差分に見せない。

### 031の共通視覚条件

-   同一人物
-   同じ顔・髪型・体型
-   不機嫌/険しい印象
-   刺青
-   大型管理リストバンド
-   不自然なくらい鮮やかな赤い服
-   周囲の明度に合わせず目立つ

赤は最初の異常を確実に発見させるためのゲーム上の識別色。

## 5-4. 031クリック後の内部情報

PHASE1の詳細は `02_game-flow.md`。

表示情報はHTMLで実装：

``` text
管理番号：031
入館：2014年8月17日
滞在期間：4,382日
状態：滞在中
外出記録：0
入館理由：事件関与
滞在区画：10階
```

「10階」を次の調査理由として明確に残す。

## 5-5. 2021年改装記録

画像：`gallery-renovation.jpg`

条件：

-   ホテル改装工事の記録写真
-   背景に業務用EV入口
-   **031を写さない**

PHASE2で「業務用エレベーター／2021年増設」を取得するまでは、通常の改装記録として見える。

取得後は2021年記録が調査対象になる。

クリック後：`facility-extension-plan.png` を表示。

工事図から理解させること：

-   2021年に業務用EVが地下へ延伸
-   その先にB2「地下増設区画」が後付けされた

図面上で「人体実験施設」と断定しない。

# 9. 直接アクセス時

`underground.html` / `truth.html`
は、必要状態未到達でURL直接アクセスされた場合に真相を露出しない。

ただし即時リダイレクトだけで済ませず、世界観を壊さない簡潔なアクセス不可表示＋通常サイトへ戻るボタンを出す。

例：

``` text
この記録は現在閲覧できません。
```

文言を過度にSF的な `ACCESS DENIED` に寄せる必要はない。
